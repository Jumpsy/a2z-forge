# Marginalia Study Tutor

This is A2Z FORGE's first functional reference product. It accepts a local plain-text or Markdown source, retrieves passages relevant to a question, cites the exact source numbers, and generates a simple retrieval-practice question. It uses no hosted model and makes no claim that lexical retrieval replaces a teacher or general-purpose tutor.

Run:

```bash
node server.mjs
```

Open <http://127.0.0.1:4178>. Load the included biology example or select your own file. Files remain in browser memory for the session.
