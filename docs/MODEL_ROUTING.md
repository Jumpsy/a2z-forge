# Model Routing

A2Z FORGE discovers available models through provider adapters when possible. It does not hardcode versioned model identifiers in core policy.

- Strategic reasoning: strongest appropriate available reasoning tier for venture decisions, architecture arbitration, difficult failures, and final synthesis.
- Production implementation: strong coding tier for features, refactoring, integration, tests, and documentation.
- Cheap research: deterministic retrieval, local extraction, or inexpensive models for classification, summaries, transcript structure, indexing, and clustering.
- Local vision: local multimodal models for frames and screenshots, escalating ambiguous judgments only when necessary.

Routing considers capability, observed task quality, context size, runtime, cost, local resources, deadline, critical path, and reserve. Provider-reported, observed, and estimated usage remain separate.
